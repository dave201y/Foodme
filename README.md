# Food Me

Food Me is a mobile-first social food journal. People can share what they ate, follow creators, save meals, and review restaurants.

## Start the app

1. Install Node.js LTS.
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm start`.
5. Scan the QR code with Expo Go, or press `w` for the browser preview.

## Current prototype

- Following feed with followed-account meal posts
- Explore feed with posts and a recipe video from accounts the user does not follow
- Create Post screen with local caption, ingredients, instructions, manual nutrition, photo/video choice, and preview
- Saved screen backed by local save state
- Profile screen with local post grid and stats
- Likes, saves, and a usable local comments sheet
- Original sample content ready to replace with real data

The first release keeps nutrition manual and user-entered. It should be labeled as approximate in the eventual production experience.
