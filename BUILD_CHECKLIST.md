# Food Me Build Checklist

## Milestones

| Milestone | Target | Deliverable |
| --- | --- | --- |
| 1. Foundation | Week 1 | Expo app, navigation shell, visual direction, sample feed |
| 2. Sharing loop | Weeks 2-3 | Accounts, profiles, follows, meal composer, photo upload |
| 3. Discovery | Week 4 | Search, creator discovery, restaurant pages, saved posts |
| 4. Community | Week 5 | Likes, comments, notifications, share links |
| 5. Trust and polish | Week 6 | Reporting, blocking, accessibility, loading and error states |
| 6. Beta | Week 7 | Test builds, analytics, bug fixes, privacy review |
| 7. Launch | Week 8 | Production release and post-launch backlog |

## Product checklist

- [ ] Email, Apple, and Google sign in
- [ ] Profile photo, bio, favorite cuisines, and dietary preferences
- [ ] Follow and unfollow accounts
- [ ] Following and For You feeds
- [ ] Meal post with image, meal type, caption, ingredients, calories, and protein
- [ ] Manual nutrition labels marked as user-provided
- [ ] Restaurant review with venue, rating, price range, photos, and text
- [ ] Search people, posts, and restaurants
- [ ] Likes, comments, saves, and sharing
- [ ] Notifications for follows, likes, and comments
- [ ] Report, block, mute, and moderation queue
- [ ] Push notifications and deep links
- [ ] Empty, loading, offline, and error states
- [ ] Responsive tablet and web layout
- [ ] Accessibility labels and dynamic text support
- [ ] Privacy policy, terms, account deletion, and data export

## Technical checklist

- [ ] Choose backend and database
- [ ] Add authenticated API client
- [ ] Add image storage and compression
- [ ] Add pagination and pull to refresh
- [ ] Add analytics and crash reporting
- [ ] Add automated tests for posting and feed behavior
- [ ] Create development, staging, and production environments
- [ ] Configure App Store and Google Play builds
